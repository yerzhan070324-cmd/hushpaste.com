Why

Anything you paste into AI is stored on someone else's server.

Hushpaste keeps your secrets out of it. Everything runs in your browser, nothing is uploaded, and the originals vanish when you close the tab. The code is on GitHub.

What it hides

It knows what a secret looks like.

  • API keys
  • Tokens
  • Passwords
  • Database URLs
  • Emails
  • Phone numbers
  • Cards
  • IBANs
  • IP addresses
  • Passports
  • KZ · IIN / BIN
  • TR · TC Kimlik
  • RU · SNILS / INN

Cards, IBANs and ID numbers are checked with their official check digits, so ordinary numbers stay untouched.

Questions

Can you see my data?

No. Everything happens in your browser. There is no Hushpaste server in the path.

What if the AI changes a placeholder?

It stays as it is. Only exact matches are restored, nothing is guessed.

Can I install it as an app?

Yes. iPhone: Share → Add to Home Screen. Android: Install app in Chrome.

Is it free?

Yes. Later there will also be a paid Pro version with a browser extension.

Has it been audited?

Not yet. The code and tests are public on GitHub, and an independent audit is planned.
