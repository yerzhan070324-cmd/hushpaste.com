Questions, answered straight.

Can you see my data?

No. Detection and replacement run in your browser. There is no Hushpaste server in the data path, and the placeholder map is held in the open tab only.

Which sites will it support?

Launch targets are the major AI chats, including ChatGPT, Claude and Gemini. Waitlist members help decide what comes next.

How accurate is detection?

Values with a known format, such as keys, tokens, IBANs and emails, are caught by pattern matching. Names and organizations are not detected automatically yet, so add them in the "extra words" box and always read the masked text before you send it. No pattern-based tool can promise to catch everything.

What if the AI rewrites a placeholder?

Restoration matches placeholders exactly. If a reply changes one, it stays as it is and is not guessed.

Is it open source?

The detection core is planned to be, so anyone can audit exactly what runs in your browser.
