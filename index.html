Why

Anything you paste into an AI chat is stored on someone else's server. Hushpaste keeps your secrets out of it.

It all runs in your browser. Nothing is uploaded or stored, and the originals disappear when you close the tab. The code is on GitHub.

What it hides

API keys and tokens, passwords, database URLs, emails, phone numbers, cards, IBANs, IP addresses, Kazakh IIN and BIN, Turkish TC Kimlik, Russian SNILS and INN, passport numbers.

Questions

Can you see my data?

No. Everything happens in your browser. There is no Hushpaste server in the path.

What if the AI changes a placeholder?

It stays as it is. Only exact matches are restored, nothing is guessed.

Can I install it as an app?

Yes. iPhone: Share → Add to Home Screen. Android: Install app in Chrome.

Is it free?

Yes. Later there will also be a paid Pro version with a browser extension.

Has it been audited?

Not yet. The code and tests are public on GitHub, and an independent audit is planned.
