WHAT IT CATCHES

28 detectors for the things that should never leave.

Every detector looks for a known shape, and many also check a checksum, so ordinary numbers are left alone. Cards pass a Luhn check, IBANs a mod-97 check, and national IDs their official check digits.

API keys and tokens

OpenAI-style sk- keys, Stripe, AWS, Google, GitHub, Slack, SendGrid, npm.

SECURITY MODEL

Nothing to steal, because nothing leaves.

Questions, answered straight.

Can you see my data?

No. Detection and replacement run in your browser. There is no Hushpaste server in the data path, and the placeholder map is held in the open tab only.

Which sites will it support?

Launch targets are the major AI chats, including ChatGPT, Claude and Gemini. Waitlist members help decide what comes next.

How accurate is detection?

Values with a known format, such as keys, tokens, IBANs and emails, are caught by pattern matching. Names and organizations are not detected automatically yet, so add them in the "extra words" box and always read the masked text before you send it. No pattern-based tool can promise to catch everything.

What if the AI rewrites a placeholder?

Restoration matches placeholders exactly. If a reply changes one, it stays as it is and is not guessed.

Does it work with Kazakh, Turkish and Russian data?

Yes. It recognises Kazakh IIN/BIN, Turkish TC Kimlik numbers, Russian SNILS and INN, passport numbers written after "passport", "паспорт" or "pasaport", local phone formats and IBANs from every country. Names written in any language can be added in the extra words box.

Can I drop a whole file?

Yes. Drop a .env, log or text file on the input panel, or use "open a file". The file is read by your browser and never uploaded.

Does it store anything?

No. There are no accounts and no cookies, and nothing you paste is saved. Close the tab and the placeholder map is gone.

Can my company use it?

Yes. The free web tool needs no installation and sends nothing anywhere, which makes it easy to approve. The Team plan adds shared rules and reports. Join the waitlist with your work email and pick Team.

Is it open source?

Not formally yet. The code of this site, including every detection rule, is already public on GitHub with tests anyone can run. An open-source license and an independent security audit are planned.
