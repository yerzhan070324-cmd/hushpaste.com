Why this matters

Whatever you paste into an AI chat is stored on someone else's server. A password there is a password someone else can read.

Chain of custody

Detection runs in your browser. The originals stay in this tab and vanish when you close it. No cookies, no tracking scripts.

Check it yourself: developer tools → Network. Read the code on GitHub.

What gets blacked out

  • API keys and tokens
  • Passwords and database URLs
  • Emails and phone numbers
  • Card numbers and IBANs
  • IP addresses
  • Kazakh IIN and BIN
  • Turkish TC Kimlik
  • Russian SNILS and INN
  • Passport numbers

Cards, IBANs and ID numbers are checked with their official check digits, so ordinary numbers stay untouched.

Questions

Can you see my data?

No. Everything happens in your browser. There is no Hushpaste server in the path.

What if the AI changes a placeholder?

It stays as it is. Restoring only swaps exact matches and never guesses.

Can I install it as an app?

Yes. On iPhone: Share → Add to Home Screen. On Android: Install app in Chrome. It opens straight to the tool.

Is it free?

Yes, the web tool and the app. Pro, a browser extension for $8 a month, and Team, $6 per user a month, are coming.

Is it open source?

The code and tests are public on GitHub. There is no independent security audit yet; one is planned together with an open-source license.
