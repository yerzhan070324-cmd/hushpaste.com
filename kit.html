PART 1

20 things you should never paste into AI

Run through this list before you paste a log, ticket, email or file into any AI chat. If something on it is in your text, mask it, swap in a made-up value, or leave it out. Tap an item to tick it off.

Credentials and secrets

Customer and personal data

Company-confidential material

Rule of thumb: if you would not post it publicly, mask it or leave it out. The free Hushpaste tool masks values with a recognisable format, such as keys, emails, IBANs and phone numbers, right in your browser. For names and codenames, add them to its extra words box.

PART 2

Ready-to-import regex rules

19 detection rules for secrets and personal data, in one JSON file. It includes everything the free web tool detects, plus formats such as SendGrid and npm tokens, secrets in URLs and US Social Security numbers. Each rule has an id, a pattern, flags, a severity and a note.

Download hushpaste-rules.json

Use it in JavaScript

const doc = await (await fetch('hushpaste-rules.json')).json();

for (const rule of doc.rules) {
  const re = new RegExp(rule.pattern, rule.flags);
  for (const m of text.matchAll(re)) {
    // if rule.group is 1, the secret is m[1], not m[0]
    // if rule.validator is set, check the match first
    console.log(rule.id, m[0]);
  }
}

Good to know. Patterns use JavaScript regular expression syntax and work in most other languages with small changes. When two matches start at the same place, the earlier rule wins. Rules with a validator (card numbers, IBANs, IP addresses) need a quick check, which the file describes in plain words. Regular expressions only catch values with a recognisable shape. They do not detect names, company names or free-text secrets, so review the result before you send anything.

PART 3

One-page AI usage policy template

Copy it into your own document and fill in the parts in [square brackets]. It is a starting point: adjust it to your company, tools and local law.

AI Usage Policy: [Company name]

Version 1.0 · Effective [date] · Owner: [name or team]

1. Purpose

This policy lets us use AI tools to work faster without exposing customer, employee or company data.

2. Scope

It applies to all employees, contractors and interns who use any AI chat, assistant, coding tool or API for work.

3. Approved tools

Use only these tools: [list of tools]. Sign in with your company account, never a personal one. Where a setting exists, turn off the use of our content for model training.

4. Never share

Do not put any of the following into an AI tool:

  • passwords, API keys, tokens, private keys and other credentials;
  • personal data of customers, employees or candidates, including contact details, IDs, payment and health data;
  • contracts under NDA or legal privilege, unreleased financials and board materials;
  • security incident details and internal network information;
  • [add anything specific to your business].

5. Mask before you paste

When you need AI help with real material such as logs, tickets, configs or emails, mask sensitive values first with an approved masking tool, or replace them with placeholders like [EMAIL_1]. Check the masked text before you send it.

6. Check the output

AI can be wrong. You are responsible for anything you use or send. Verify facts, code and legal or financial statements before relying on them, and review AI-written text before it reaches a customer.

7. If something slips

If you paste restricted data into an AI tool by mistake: stop the conversation, rotate any exposed secret straight away, and tell [security contact] within [24 hours]. We treat an honest report as a chance to fix a problem, not as a reason for blame.

8. Exceptions

Anything not covered here needs written approval from [owner].

9. Review

We review this policy every [6 or 12] months and whenever we add a new AI tool.

Acknowledgement

I have read and understood this policy. Name: ____________________ Date: ______________

This kit is general information and a starting template, not legal advice. Have a qualified professional review any policy before you adopt it.
